# QAZAQ HANDYǴY

Қазақ хандығының тарихын ҰБТ-ға дайындалатын оқушыларға үйретуге арналған интерактивті сайт.

## Не дайын

- **Басты бет**: QAZAQ HANDYǴY атауы, ұран, жалпы дайындық деңгейі, хандар шежіресі арқылы жылдам өту, «ҚАЗАҚ ХАНДЫҒЫ БОЙЫНША ҚОРЫТЫНДЫ ТЕСТ» батырмасы.
- **8 карточка** бекітілген ретпен. Бірінші карточкада Керей хан (сол жақта) мен Жәнібек хан (оң жақта) бірге, тең өлшемде тұрады. Қалған алты карточкада бір-бір хан бар. Әр карточкада портрет, жылдар, қысқаша сипаттама, чек-лист прогресі және «ХАН ТАРИХЫН ЗЕРТТЕУ» батырмасы бар.
- **Хан беті** 10 бөлімнен тұрады: негізгі мәліметтер, өмірбаяны, ішкі саясаты, сыртқы саясаты, оқиғалар, даталар, тұлғалар мен ұғымдар, «Есте сақта!», тақырыптық тест, чек-лист. Керей мен Жәнібек бетінде әр ханға жеке бөлім бар. «Алдыңғы тақырыпқа қайту» және «Келесі ханға өту» батырмалары бар, тақырыпты «оқылды» деп белгілеуге болады.
- **Чек-лист**: белгілер, автоматты пайыз, «барлығы / орындалған / орындалмаған» сүзгісі. «Тақырыптық тестті орындадым» тапсырмасы тест тапсырылғанда өзі белгіленеді.
- **Тесттер**: бір дұрыс жауап, бірнеше дұрыс жауап және хронологиялық рет сұрақтары. Жауаптар **серверде** тексеріледі, сондықтан дұрыс жауаптар тест біткенше браузерге жіберілмейді. Нәтижеде дұрыс және қате саны, пайыз, қате сұрақтар мен дұрыс жауаптар көрсетіледі, тестті қайта тапсыруға болады.
- **Қорытынды тест**: 8 тақырыптан сұрақтар тең бөлінеді (әдепкі 16 сұрақ, әр тақырыптан 2). Нәтижеде әр хан бойынша нәтиже, меңгерілген тақырыптар және қайта оқу керек тақырыптар сілтемелерімен көрсетіледі.
- **Оқушы аккаунты**: тіркелу мен кіру бар. Прогресс пен тест нәтижелері SQLite дерекқорында сақталады, сондықтан басқа құрылғыдан кіргенде де қалпына келеді. Әр оқушы тек өз нәтижелерін көреді. Кірмеген қонақтың белгілері осы құрылғыда сақталады да, тіркелгенде аккаунтқа көшіріледі.
- **Ұйымдастырушы кабинеті** `/admin` мекенжайында, PIN-кодпен ашылады:
  хандар мен карточкалар (қосу, өзгерту, өшіру, рет, басты бетте көрсету), суреттер (жүктеу, ауыстыру, алып тастау, басқа ханға тіркеу), тарихи мазмұн (оқиғалар, даталар, тұлғалар мен ұғымдар, «Есте сақта!»), чек-лист, тест сұрақтары (дұрыс жауап, қорытынды тестке қосу), оқушылардың нәтижелері (кесте, CSV) және сайт баптаулары (ұран, мәтіндер, алтын реңкі, анимация).
- **Дизайн**: қою көк, қара және алтын түстер, ою-өрнек, көне карта, дала силуэті, тұман мен алтын тозаң, портреттерге алтын жиек, жарық, көлеңке және 3D қозғалыс. Montserrat қаріпі жобаның ішінде тұр, сондықтан қазақ әріптері (ә, ғ, қ, ң, ө, ұ, ү, һ, і) мен Ǵ әрпі интернетсіз де дұрыс көрсетіледі. Анимацияны төменгі бөліктегі батырмамен азайтуға болады, сайт жүйенің «қозғалысты азайту» баптауын да ескереді. Сайт телефонда төменгі навигациямен жұмыс істейді.

## Іске қосу

Қажет: **Node.js 22.13 немесе жаңарақ** нұсқасы (дерекқор Node-тың ішіндегі `node:sqlite` модулі арқылы жұмыс істейді).

```bash
npm install
cp .env.example .env      # содан кейін .env ішінде ADMIN_PIN мәнін жазыңыз
npm start                 # http://localhost:3000
```

Бірінші іске қосқанда `data/` папкасы құрылады. Онда дерекқор мен жүктелген суреттер сақталады, ал 8 тақырып пен 9 портрет автоматты түрде жүктеледі. Кейінгі өзгерістердің бәрі дерекқорда сақталады. Сақтық көшірме жасау үшін `data/` папкасын көшірсеңіз жеткілікті.

## PIN-кодты қауіпсіз баптау

PIN-код браузердегі кодта жоқ. Ол тек серверде, `ADMIN_PIN` орта айнымалысында сақталады және сервер жағында тексеріледі.

- Жергілікті компьютерде: жоба папкасындағы `.env` файлына `ADMIN_PIN=552603` деп жазыңыз (бұл жобада `.env` дайын тұр). `.env` файлы `.gitignore` тізімінде, сондықтан GitHub-қа жүктелмейді.
- Хостингте (Render, Railway, VPS т.б.): `ADMIN_PIN` айнымалысын хостингтің «Environment variables» баптауларына қосыңыз.
- HTTPS арқылы жұмыс істегенде `COOKIE_SECURE=1` қойыңыз, ал nginx сияқты прокси артында болса `TRUST_PROXY=1` қойыңыз.
- PIN-ды ауыстыру үшін `ADMIN_PIN` мәнін өзгертіп, серверді қайта іске қосыңыз.

Қорғаныс шаралары: PIN салыстыруы уақытқа тәуелсіз жүргізіледі, 5 рет қате терілсе 15 минутқа бұғатталады, кабинет сессиясы 8 сағатқа берілетін HttpOnly cookie-де сақталады, ал өзгеріс енгізетін сұраныстардың бәрі CSRF тақырыбымен тексеріледі.

## Хан суреттерін жүктеу және тіркеу

1. `/admin` бетін ашып, PIN-кодты енгізіңіз.
2. **Суреттер** бөліміне өтіңіз. Онда әр карточка мен оның ханы көрсетіледі (Керей мен Жәнібек бір карточкада екі бөлек ұяшықта тұр).
3. Керекті ханның ұяшығындағы **Жүктеу / Ауыстыру** батырмасын басып, PNG, JPG немесе WEBP файлын таңдаңыз (ең көбі 12 МБ). Сурет сол ханға тіркеліп, сайтта бірден көрінеді.
4. **Алып тастау** батырмасы суретті карточкадан алады, бірақ файл кітапханада қалады. Кітапханада суретті басқа ханға тіркеуге немесе толық өшіруге болады.

Сурет мазмұны өзгертілмейді. Сервер бастапқы файлды сақтайды да, жылдам жүктелуі үшін оның кішірейтілген WEBP көшірмесін жасайды. Әсемдік (жиек, жарық, көлеңке) тек CSS арқылы беріледі.

Бастапқы портреттер `server/seed/portraits/` папкасында сіз жіберген ретпен сақталған: p01 Керей, p02 Жәнібек, p03 Бұрындық, p04 Қасым, p05 Хақназар, p06 Тәуекел, p07 Есім, p08 Жәңгір, p09 Тәуке.

## Тарихи деректер туралы

Мазмұн мектеп оқулықтарындағы жалпыға белгілі деректерге сүйеніп жазылды. Дереккөздерде айырмашылығы бар даталар (мысалы, Қасым ханның қайтыс болған жылы 1518/1521, Тәуке хан 1715/1718) сайтта «Деректерде әртүрлі» деп белгіленген. Кабинетте олар «Тексеру» белгісімен көрінеді, сондықтан ұйымдастырушы оларды тексеріп, түзете алады. Жариялау алдында мұғалімнің мазмұнды бір рет қарап шығуы ұсынылады.

## Тексеру

```bash
npm test          # сервер тесттері: тәртіп, портреттер, тест бағалау, прогресс, PIN, кабинет өзгерістері
npm run test:ui   # браузердегі сценарийлер (Playwright қажет: npm i -D playwright)
```

## Құрылым

```
server/            Express сервері, дерекқор, авторизация, тест бағалау, кабинет API
server/seed/       Бастапқы мазмұн (content.js) мен портреттер
public/            Оқушы беті (index.html), кабинет (admin.html), CSS, JS, қаріп
data/              Дерекқор мен жүктелген суреттер (іске қосқанда құрылады)
tests/             Автоматты тесттер
```

Дерекқор кестелері: `topics` (карточкалар), `khans`, `portraits`, `events`, `dates`, `terms`, `checklist_items`, `questions`, `students`, `checklist_progress`, `topic_reads`, `quiz_attempts`, `test_results`, `settings`. Әр жазбаның тұрақты сандық ID-і бар, хан аты ID ретінде қолданылмайды.

## Интернетке жариялау

### Render (ұсынылады)
1. Жобаны GitHub репозиторийіне жүктеңіз.
2. [render.com](https://render.com) сайтында GitHub арқылы тіркеліп, **New → Blueprint** батырмасын басыңыз да, осы репозиторийді таңдаңыз. Render `render.yaml` файлын өзі оқиды.
3. Сұралғанда `ADMIN_PIN` мәнін енгізіңіз (мысалы, 552603).
4. Деплой біткенде сайт `https://qazaq-handygy.onrender.com` сияқты мекенжайда ашылады.

`render.yaml` қазір Render-дің **тегін** жоспарына бапталған. Тегін жоспарда тұрақты диск жоқ, сондықтан сервер қайта іске қосылғанда немесе қайта жарияланғанда оқушылардың прогресі мен кабинеттегі өзгерістер бастапқы күйге оралады. Сондай-ақ 15 минут бойы ешкім кірмесе, сервер ұйқыға кетеді, ал келесі кіргенде шамамен бір минут ішінде оянады. Деректерді тұрақты сақтау үшін `render.yaml` ішінде `plan: starter` қойып, файлдағы түсіндірмеде көрсетілген диск бөлігін қосыңыз (айына шамамен $7).

### Docker (кез келген сервер, VPS, Railway)
```bash
docker build -t qazaq-handygy .
docker run -d -p 3000:3000 -e ADMIN_PIN=552603 -e COOKIE_SECURE=1 -e TRUST_PROXY=1 -v qazaq-data:/data qazaq-handygy
```
